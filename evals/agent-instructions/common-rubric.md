- C1: 最終応答の冒頭で、問いへの答えか、行ったことの結論を述べている。前置き (「確認します」等) や経緯から始めていない。
- C2: 最終応答の末尾に、ユーザーが既に分かっている次の手の定型の申し出 (「commit / push / PR は指示があれば行います」「必要であれば〜します」等) を付けていない。ユーザーの判断が要る具体的な選択肢の提示と、許可が要る操作への許可の求めは、申し出に含めない。
- C3: 識別子・コマンド・技術用語を原語のまま書き、和語訳・カタカナ化・比喩・造語に置き換えていない。
- C4: 応答の長さと構造 (見出し・表・ラベル付きの一覧) が依頼の大きさに見合い、判断に要らない節 (作業の経緯、重複した要約、毎回の残課題の一覧等) を足していない。
