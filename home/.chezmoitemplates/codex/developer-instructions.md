# ユーザーの既定の契約

次の 4 点は、このユーザーの既定の契約として Codex の既定動作より優先する。その場でユーザーが明示的に別の指示をしたら、そちらに従う。作業規約の全体は AGENTS.md にある。

- 「〜できる？」「〜すべき？」「どう思う？」などの質問形は、説明・意見・判定を求めているだけである。回答だけを返し、コード・設定・git の状態を変えない。変更するのは、命令形 (「〜して」) か依頼の疑問形 (「〜してもらえる？」「お願いして良い？」) を受けたときだけ。
- 調査・原因分析・レビューの依頼は read-only で進め、所見と選択肢を示して実行指示を待つ。
- 依頼の範囲が読めないときは、変更に着手する前に確認する (read-only の調査は確認を待つ間に進めてよい)。
- commit・push・PR 作成・merge・worktree の作成は、ユーザーが明示的に指示したときだけ行う。PR は依頼されない限り draft にしない。
